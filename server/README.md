# GuGu Server (Python Backend)

The **GuGu** server is a lightweight Python-based Flask/SocketIO service designed to handle encrypted communication and notification forwarding for the **GuGa** Android app.

## Prerequisites

- **Linux OS** (Ubuntu/Fedora/Arch/openSUSE supported).
- **Python 3.10+**.
- **Sudo Access** (required for `post.py` to install `dbus-monitor` if it's missing).

## Setup instructions

1.  **Run Setup Script**:
    ```bash
    python3 post.py
    ```
    This script will:
    - Check system compatibility (Linux only).
    - Detect your package manager and install `dbus-x11` (or equivalent).
    - Create a Python virtual environment and install `requirements.txt`.
    - Download the latest `cloudflared` binary for secure remote access.
    - Create a default `.env` configuration.

2.  **Start the Server**:
    ```bash
    python3 server.py
    ```
    The server will start on port `6769`. A QR code will be printed in your terminal for easy pairing with the Android app.

3.  **OS Notifications (Optional)**:
    To forward notifications from your Linux desktop to your phone, run the alerter in the background:
    ```bash
    python3 os_notification_alerter.py &
    ```

## Configuration (.env)

| Variable | Description | Default |
|----------|-------------|---------|
| `PORT` | Local server port | `6769` |
| `MODE` | `lan` or `cloudflared` | `lan` |
| `ENABLE_OS_NOTIFICATIONS` | Enable D-Bus monitoring | `True` |

## Security

- **Encryption**: All communication (except initial pairing) uses AES-256-GCM.
- **PIN Pairing**: New devices must enter a one-time 8-digit PIN generated by the server.
- **Token Expiry**: Browser sessions expire after 1 hour, while app sessions are valid for 30 days.

## Development

- `server.py`: Core Flask/SocketIO logic.
- `os_notification_alerter.py`: D-Bus monitor using subprocess.
- `trusted_devices.json`: Persisted pairing tokens (keep this file secure).
